# 花吻在上5 — PC喵兼容补丁

本项目用于解决《花吻在上5 ～爱上你的幸福～》PC 汉化版在 PC喵中无法正常启动的问题。

原汉化版在 PC喵中启动时会提示「无法读取数据」，无法进入游戏。本补丁通过调整汉化程序的封装方式，使中文版能够在 PC喵中正常启动。

已在 Mac 和 iPhone 的 PC喵中验证成功。

## 下载与使用

- **兼容补丁：** [GitHub Releases](https://github.com/rereva0611/hanabira5-nekopc-fix/releases/latest)
- **花吻资源站：** https://hana.ywy.moe/

使用方法：

1. 准备《花吻在上5》的 PC 汉化版游戏文件。
2. 下载并解压兼容补丁。
3. 将 `HANABIRA5_CN_FIX.EXE` 和 `srp` 文件夹放入原游戏目录。
4. 在 PC喵中运行 `HANABIRA5_CN_FIX.EXE`。

本补丁仅包含兼容程序及中文脚本，不包含完整游戏资源，无法独立运行。

## 修复说明

原 PC 汉化版使用 MoleBox 封装，在 PC喵中存在兼容性问题。

本补丁进行了以下调整：

- 修复 PE 程序入口及导入表。
- 将中文脚本外置到 `srp` 文件夹，绕开 MoleBox 封装。
- 不使用片头文件 `op.mpg`，减少启动等待时间。
